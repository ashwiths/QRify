# QRify

A React QR code generator starter built with Vite and Tailwind CSS.

## Start the website

```sh
npm run dev
```

## Installed dependencies

- `react` and `react-dom`: build and render the website UI.
- `tailwindcss` and `@tailwindcss/vite`: style the interface with utility classes and load Tailwind through Vite.
- `qrcode.react`: render QR codes from a URL or text.
- `lucide-react`: provide the small interface icons.
- `animo-core`: the Animo JavaScript animation package (the project's published package name).

Vite and the React Vite plugin run the local development server and create production builds. `oxlint` is included for linting.
